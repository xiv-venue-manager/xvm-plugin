**XIV Venue Manager plugin v4.0.1**

A clearer Shifts tab and a filter for services.

- Open event shifts show the event they belong to, and the open board only lists shifts for your roles.
- Shifts are grouped by date, and your own shifts sit above the open ones.
- Role changes made on the dashboard show up without reloading the plugin.
- New filter box on the Inventory tab and in the Sales service dropdown.
- Fixed the Link button leaving the rest of the window greyed out.

Update from Dalamud's plugin installer. The full history is in the plugin's changelog window.
